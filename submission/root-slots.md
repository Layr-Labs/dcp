# Robust scoring with one capped root per source block

Use the two-level schedule, centered odd decoder, and bounded coherent search from the accompanying files, with the overrides below. The bank wrapper and its sizes, whole-bank cutoffs, verification reserve, and success analysis are replaced in full. All supplied inputs are still single forward source requests. Model and success obligation are stated in submission.json.

For n<1024 execute a single direct stage with K=2^20 n consecutive copies. Read each copy's native Fourier label using the BASE13 Section 3 instrument with Qcap=K, use X to make the row phase positive, and then measure a private uniform X/Y basis. Use the exact X/Y score based on the unshifted label with phase k*a/N for each candidate a modulo N. For ideal records the true mean is 1/2 and the wrong mean is zero by orthogonality of the uniform Fourier label. The same concentration and margin proof given below applies to these direct records: the joint good label coupling adds failure at most 2^-14 and the exact malformed count is at most K/32 because epsilon(n)<=1/32. Use the common threshold 27/64 and bounded Grover. All per-branch resources on this finite range are finite and counted. The exact finite acquisition count is K.

For n>=1024 compute the two-level profile of coherent-search.md and h=2R. Determine all odd and direct stage widths from N before acquiring any copies. There are at most sixteen stages. In each stage collect K=2^20 n score records. Every record gets a consecutive disjoint slot of exactly P=2^10 n^2 freshly acquired source copies. A slot attempts to generate exactly one root using the appropriate unchanged recursive low-residue combiner, then measures the successful row in an independent private uniform X/Y basis. As soon as it succeeds or aborts, discard any leftover copies in that slot. Abort emits the special record whose contribution is zero for all candidates. Compute and enforce weighted-attempt cap 2^16 * 6 * 2^R and raw cap P, including any last unfinished attempt. Start a fresh controller after each slot. Source slots for subsequent stages are acquired regardless of scoring and search outcomes. Thus Q=S K P for the predetermined stage count S. There is no adaptive dependence of this partition on preceding data.

The root source and work estimates here are per root: expected raw requests <=18 q0 and expected sum of attempt weights <=6*2^R, by the BASE13 combiner analysis ported in coherent-search.md (its H0 factors count multiple roots and do not enter these estimates). Since q0=(2R+1)^2<=n^2/4, Markov bounds the ideal source-cap failure by (18/4)/2^10 and its work-cap failure by 2^-16. The label extraction circuit uses P for its precision cap, making the original full-coupling discrepancy at most 2^-14 per slot. The sum of these three bounds is less than 1/192. For a clean slot define a coupling to an ideal uncapped root record using fresh ideal extension samples and the same low-transcript measurements and fair basis coin up to any discrepancy. Success or failure of that coupling need only be considered in the reduced product marginal of all clean slots, grouped into the predetermined schedule. In particular, neither a union bound over all roots nor a clean whole stage is needed. For each fixed candidate the ideal score is in [-1,1]; the actual score with rounded table and abort handling is in [-1,1] as well. The absolute expectation discrepancy from cap and label effects is less than 1/96 before table rounding.

In the first direct stage, if used, retain the unshifted full signed integer label after truncation and use the existing high-valuation score. In the odd stages use the same centered labels, normalized frequency and stage-specific public multiplier as in terminal-block.md. These physical operations depend on N and the stage number, and on local slot outcomes only. Earlier search outputs only specify the later grid subinterval, never affect the instrument gathering a record.

For the dyadic residual stages, omit preparation-time secret subtraction. In the predetermined stage with N=M0*2^D, retain the full canonical Fourier label k and the logical combining label a=k mod 2^D at a leaf. At a successful pair combine the two label columns separately by the same signed sum prescribed by the two identified basis strings. Low-residue operations read the logical column only; the physical phase at a leaf is exp(2 pi i k s/N) and at the root is exp(2 pi i F s/N), with F the full signed label column accumulated with the pair differences. F modulo 2^D equals the logical label modulo 2^D. The labels occupy O(n) bits since the support is at most q0 and individual k<N. Pair choices continue to depend only on logical low parts, so the uniform unused-block proof applies to the logical column. The work and space estimates for signed labels change by a fixed factor. No rotation implementing a fractional phase correction is used.

At a residual stage the previous decoded prefix is c modulo M0. Let e=min(D,h) and cancel D-e low bits as in terminal-block.md. Test t in [0,2^e) with score term

    Z cos(2 pi F(c+M0*t)/N - beta),

evaluated with the same exact rational table convention. This is a full-secret candidate extension, and the label gathering is independent of c. If c is correct, write s=c+M0*u as an integer modulo N. Then the difference of the ideal phases is 2 pi F(u-t)/2^D. Since F modulo 2^D is divisible by 2^(D-e) and the normalized logical root is uniform modulo 2^e, the exact mean is 1/2 for t=u mod 2^e and 0 for any other t. The scored candidate matches the correct next e bits even when the undiscovered higher bits of u are nonzero. This removes the need for a c-dependent slot instrument, and the wrong-prefix branch still has a finite score and finite search.

## Simultaneous concentration

Fix the malformed set. A slot meeting it is called contaminated. Across the complete run there are at most epsilon Q contaminated slots. Given S<=16, each stage has at most K/32 contaminated slots since epsilon S P <= 1/32, with epsilon(n)=1/(2^19 n^2). Their contribution is bounded pointwise; no conditioning on their records is used. All uncontaminated slots have true product marginal. Their record-gathering operations are local and use independent coins and no earlier search outputs. Even across different stages, the reduced record law on these slots is therefore a product. Interleaved search and decisions on earlier records do not select future slot instruments, so can also be analyzed as functions of the complete record array and search coins after it has been generated. This is a statement about joint output laws, not a requirement to retain every stage's stored data.

For a fixed stage and a fixed candidate, let X_i be its actual rounded score on each uncontaminated slot. Hoeffding gives probability at most 2 exp(-K/131072) that |sum_i (X_i-E X_i)| > K/256, since the clean count is <=K and each range has length <=2. For odd stages union over the entire public dyadic grid at the actual stage denominator, not just the selected subinterval. Each denominator exponent is <=3n: j*stride <= n for stages up to the first final rounding radius, and ceil(log2(A sqrt(q0)))+12 <= h+ceil(log2 n)+12 <=2n. For direct residual stages union over all c and t, of which M0*2^e<=N<=2^n. For the first direct stage there are at most 2^(h+1)<=2^n candidates. Thus across the stages the failure probability is bounded by 32*2^(3n)*exp(-8n)<1/256. The stagewise normalization always uses K, including any records whose score is zero.

Let f be the actual fraction of contaminated records in a stage, so f<=1/32. For a candidate with ideal score mean mu, the sum of the clean expectation contributions before rounding, normalized by K, differs from (1-f)*mu by less than 1/96 by the slot coupling. Combining that with concentration and table error gives total clean error less than 1/96+1/256+1/128=17/768, since the odd table is at least as accurate. Each contaminated contribution is bounded in [-1,1], so its total effect is within [-f,f]. In the finite branch we instead use the joint label coupling event; it leaves the clean deviations no larger than these same bounds.

For the centered odd grid the near-point expected score is >999/2000 from the original centered second moment. For all far points, the centered root characteristic magnitude is at most 1/8: the reduced circular argument is at least 2^(-stride-2) and at most 1/2, with stride=h-4 and A=2^h, so the geometric bound is 1/(2 A 2^(-h+2))=1/8. Thus their expectation is at most 1/16. For a direct stage the true mean is 1/2 and every wrong mean is at most 3/8, including the high-valuation branch. Use the single common rational threshold 27/64. At 0<=f<=1/32 the following endpoint estimates hold:

    (1-1/32)*(999/2000) - 1/32 - 17/768 > 27/64,
    (1-1/32)*(3/8) + 1/32 + 17/768 < 27/64.

The first is a lower bound for all true, or odd true-near, candidates. The second is an upper bound for all wrong direct candidates and far odd candidates. The left expression for the lower bound decreases with f, and the upper one increases. So the threshold works simultaneously for each selected true-prefix range. The common marking threshold explicitly replaces both archived thresholds. Score values always stay in [-1,1], with table endpoint clipping if needed. Each successful verified search advances the true-prefix induction. Joint failure is bounded by 1/256 for concentration, 2^-14 for the finite label coupling when applicable, and 16*2^-32 for search. This is below 1/8. The model permits arbitrary entanglement of contaminated systems with clean ones subject to the fixed-position product-marginal guarantee.

## Joint costs

Only one root is in progress at a time. Retain K current stage records plus the fixed-depth controller and table scratch. One record stores at most two O(n)-bit label fields and constant flags. All quantum registers, including Grover work, fit O(n), and classical space is O(n^2). Lookup, score, and gate addresses cost O(log n); all workspace is reused after each stage. Implement the coherent residual extension address and every modular product with the exact reversible arithmetic in fast-score-arithmetic.md. It supersedes the schoolbook score arithmetic while preserving every marking decision, record range, and branch cap.

There are O(2^R q0^(1/4)) Grover iterations and checked trials. The new arithmetic charges O(n^(13/5)) total work per marked predicate, including uniform indexed control, so the search work is O(2^R q0^(1/4) n^(13/5)). The total weighted combiner budget over the constant number of K-slot stages is O(n 2^R). Per unit weight its charged work is O(n^2 (log2 n)^(3/2)), using the inherited combiner, and that cost contributes at most O(2^R n^3 (log2 n)^(3/2)). This is absorbed by O(2^R n^(31/10)) since q0^(1/4)=O(n^(1/2)), and direct and odd search together are bounded by O(2^R n^(31/10)). Source acquisition, label extraction and other loop work are polynomial with the same depth-two caps. Using 2^R=O(2^(n/6) n^(1/3)) gives total sequential work O(2^(n/6) n^(103/30)). The exact and asymptotic acquisition count and the two storage bounds are as previously proved. All bounds refer to the same specified execution and include all abort and malformed branches. The growth indices are 1, 0, 0, 0.
