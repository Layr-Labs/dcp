# Full backward profile and clean score slots

For n<1024 run the finite shadow search in BASE13 Sections 3 and 8 with its original accuracy and acquire exactly mF=2^20(n+16) copies. That branch has clean failure below 2^-8 and uses no oracle other than source copies. All operations there have finite uniform cost on this fixed range. In the main branch use the following public parameters and operations.

For integer v>=1 let delta(v)=ceil(log2(3(2v+1))), evaluated as an integer bit length. For a possible height R start its list at v=R and repeatedly set v to v-delta(v) while the next value is positive. Treat this list in reverse, so levels are ordered v_1<...<v_d=R. Find the least R with 2 sum_i v_i>=n by scanning positive integers in order; no monotonicity hypothesis is needed. The height ceil(n/2) is feasible using just its first term. Let q0=product_i(2v_i+1), with exact integer computation. Set terminal width h=R. For the odd or initial direct reduction let d0=floor(log2 N) and B=d0-h, so 0<B<d0 and the profile capacity covers B. For a remaining dyadic stage at division N=M0*2^D, let e=min(D,h) and cancel D-e bits. This is also within the capacity. The actual widths b_i are allocated greedily from the top, with b_i<=2v_i, exactly as in BASE13 Section 4. A zero-width level simply invokes the next lower level. A leaf is always the same native readout using the proper public odd multiplier or the unshifted direct labels described below.

## Profile envelope

Because the values are distinct positive integers, 2 sum_i v_i<=R(R+1), so R>=sqrt(n)-1. For a trial height r put D_r=delta(r), an upper bound on any positive step in its list. Its j-th term counting downward from r is at least r-j D_r whenever that is positive. For the descending sequence of nonnegative values r-j D_r, the sum is at least the integral from 0 to r/D_r of r-x D_r. Thus twice the capacity sum for r is at least r^2/D_r. This comparison also covers the last partial step and integer rounding.

As n increases, take the witness r=ceil((709/1000) sqrt(n log2 n)) for analysis only. The actual scan never needs to form this real number. For the witness D_r/(log2 n) tends to 1/2, by the logarithm of r and the constant in 3(2r+1), whereas (709/1000)^2>1/2. Therefore r^2/D_r>=n eventually, implying R<=r. The strict coefficient gap 709/1000<71/100 absorbs every fixed polynomial factor in n in a bound poly(n) 2^R. Any finite exceptional range contributes a finite absolute constant, with the same search and guards. No parameter uses an uncomputed analytic threshold.

The last positive value v_1 is at most 6: for v>=7, 3(2v+1)<=2^(v-1), by the base v=7 and the fact that doubling its affine left side covers the next value. Therefore delta(v)<v for v>=7. The product of 3(2v_i+1) over the full list is bounded by

    2^(sum_i delta(v_i)) = 2^(R-v_1+delta(v_1)) <= 2^(R+6).

Here the interlevel decrements telescope, and delta(v_1)<=6. In particular q0<=2^(R+6), each signed label has O(n) bits, and the nominal maximum support bounds every root by the same incidence induction as BASE13. On the main branch R>=31, so A^2=2^(2h)>=q0. The mean-square and geometric-sum centered-root estimates in terminal-block.md consequently hold with these actual parameters.

## Fixed guards and local instruments

The algorithm uses the modulus branches of terminal-block.md and the independent record instruments of root-slots.md. For a<B, with a=v2(N), use the odd-part score stages with stride max(1,h-4), their public CRT multiplier, the centered truncation interval and their explicit dyadic grids, followed by the remaining dyadic residual stages. For a>=B, use the first direct stage modulo N/2^B after truncation and cancellation. It is followed by the dyadic residual stages, using the unshifted source extraction. At a residual leaf retain both the full canonical label k and its logical reduction modulo 2^D. At successful pairing apply the same signed combination to both labels. All low selection acts on the logical column only. The actual root's full phase is exp(2 pi i F s/N). Given a previously verified prefix c modulo M0, evaluate each candidate extension with the full-phase argument F(c+M0*t)/N. This is exactly the prefix-independent record law and correctness proof in root-slots.md. It requires no source correction based on intermediate outcomes. The record acquisition schedule depends only on N.

Let S be the resulting predetermined number of score stages. The odd radius stopping rule needs at most n stages, the residual loop uses at most n, and the optional initial direct stage adds at most one, so S<=2n+1. In each stage generate K=2^20 n records in disjoint consecutive slots of exactly P=2^(R+20) fresh acquisitions each. Each slot runs at most one root call, applying weighted attempt cap W=2^16*3d*2^R and raw cap P. Abort on a request that would exceed either cap, producing an all-zero-term record. On success measure the row in a private uniformly random X/Y basis and retain its signed label fields, basis and sign. After success or abort discard any remaining copies in the slot. Use P as BASE13's native Fourier label precision cap. The code runs all slots even on wrong-prefix or failed-search branches. Thus the model counts exactly Q=SKP acquisitions, even if some are used purely as padding.

For the ideal uncapped comparison, BASE13 Sections 4 and 5 give success probability at least 1/3 per positive-level attempt. The low-transcript argument applies by induction through the finite actual depth d. The children of any attempt on ideal inputs are fresh, and conditioning on earlier failed attempts does not change their low-input law for the new attempt. Write r_j=b_j+1. Repeated conditional expectation then bounds the number of level-i attempts per root in expectation by 3 product_(j>i)(3r_j), skipping zero widths. Since 3r_j<=2^delta(v_j) and the complete higher-level product telescopes, this is at most 3*2^(R-v_i). Weighting by 2^v_i and summing gives 3d*2^R. Expected raw acquisitions are at most 2 product_j(3r_j)<=2^(R+7), using the at-most-two extractor draws for a truncated leaf and exactly one for dyadic residuals. These bounds allow zero-width paths without introducing additional attempts.

Each clean slot has source exhaustion probability at most 2^-13 and work exhaustion at most 2^-16 by Markov's inequality. The full native label comparison adds at most 2^-14 per slot. Thus each actual record can be coupled to the ideal uncapped record with discrepancy less than 1/1024. This bound is used in expected scores, not union-bounded over the slots. A slot is a local instrument with independent private coins and no earlier-search input, hence all actual records are independent in the perfect source model. Caps count every attempt including the last allowable one, and the total pending stack has one path. Parent setup before the weight debit is charged to visited descendants or to the one pending path. Padding always remains within the raw acquisition count.

## Uniform scoring and search success

The odd stages use the centered mean-square grid and far-score bound in terminal-block.md. The direct stages use the same exact trigonometric table and threshold as in coherent-search.md. For each stage compare fixed actual rounded scores to the uncapped score means. Each term is in [-1,1], clipped at endpoints if needed, and the expectation discrepancy is at most 2/1024 plus the respective table error. Hoeffding bounds the probability of a larger than K/256 fluctuation of a fixed score by 2 exp(-K/131072)=2 exp(-8n).

Take the union over each odd stage's entire public dyadic grid, using exponent at most 3n: j*stride<=n before the final radius, and ceil(log2(A sqrt(q0)))+12 is at most h+(R+6)/2+13<=2n in the main range. Also union over all direct candidate extensions including all possible prefixes c. Their total within each stage is at most N, and the initial direct stage has fewer than 2^(h+1)<=2^n candidates. Thus a simultaneous concentration event has failure bound 2(2n+1)2^(3n) exp(-8n)<1/256 on the main branch. On this event each true-prefix odd stage has a near mark and no far marks at threshold 12/25: true-near mean >999/2000, far mean <37/80, total score difference at most 1/256+2/1024+1/625<1/100. Direct threshold 7/16 separates a true mean 1/2 from wrong means at most 3/8 with total deviation at most 1/256+2/1024+1/128<1/64. In a dyadic stage "true" means the next e bits. These simultaneous guarantees cover the actual earlier-searched prefix and introduce no conditional distribution assumption.

Use the verified bounded Grover schedule of coherent-search.md, but take exactly 128 ceil(log2(n+2)) trials at each doubling scale up to the first power of two M with M^2>=16 times the padded candidate count. Its proof gives failure at most (n+2)^(-32) in a stage with a mark; the number of stages is at most 2n+1. The additional failure bound is below 1/256. Hence with probability at least 7/8 all branches recover the complete secret under the declared ideal-input promise. Verification and caps are enforced even on unsuccessful branches. The stage-specific arithmetic can be implemented by the ordinary reversible schoolbook predicates in coherent-search.md, using the full phase argument in each residual extension as in root-slots.md.

## Branchwise counts and storage

The combiner and label operations are uniform bit arithmetic and exact Clifford+T over O(n)-bit labels, with per-attempt work bounded by poly(n) 2^v at height v using the explicit bounded-count discovery circuit in BASE13 Section 4. Every retained weight is charged, and polynomial overhead for an incomplete branch is covered by the counted descendants and one saved path. Per leaf acquired and processed, label precision has O(R+log(n+2)) bits for its probe schedule, so processing each source copy is polynomial. The caps give total slot work poly(n) 2^R per record, including padding and all failures. For odd search there are O(2^h sqrt(q0)) grid points per stage, hence poly(n) 2^(h/2) q0^(1/4) total search work per stage including predicate evaluation. Since h=R and q0<=2^(R+6), that is poly(n) 2^(3R/4). The direct search is no larger. K and S are polynomial, so T=poly(n) 2^R as an upper bound. The exact Q above is also at most poly(n) 2^R. Both are O(2^((71/100) sqrt(n log2 n))) by the profile envelope.

For the space bound, split the v_i values at sqrt(R). Those at least sqrt(R) have step delta(v)>= (log2 R)/2, so there are O(R/log R) such terms and their sum is O(R^2/log R). Smaller positive values sum to O(R) because they decrease in distinct integer steps. Together sum_i v_i=O(n), since R<=O(sqrt(n log n)) and R>=sqrt(n)-1. In depth-first execution an active frame keeps at most b_i+1 child rows and their O(n)-bit labels. Across frames this is O(sum_i v_i)=O(n) rows and O(n^2) classical bits. The full signed label column, counters, profile data and scratch labels take the same order. Only the currently executing combiner or leaf readout needs its arithmetic and discovery workspace, reused in O(n) qubits. All remaining earlier frames retain just their partial children and polynomial-width counters. The one stage's K records use O(n^2) bits, and coherent score arithmetic uses O(n) qubits rotated among the registers. Classical gate and memory address width is O(log n); it is charged throughout in the polynomial overhead. No exponentially sized tape of source copies, quantum-addressed memory, or exponentially sized circuit description is allocated. The declared exponents and their exact indices follow.
