## 1. Instruction selection and fields

The physical compiler statically distinguishes (a) P logical value bits and arithmetic/quantum operations, (b) physical metadata for translating those operations. P operations keep their literal bit expansion: a modular multiplication, comparison, LOOKUP, generated gate loop or residue update is never a unit-cost word instruction. Their bit operations are counted in C_P. They read/write their logical bits with proof5 READ/WRITE.

Metadata consists of owner IDs, row IDs, field offsets/bounds, slot descriptors and the constant-size eight-word bindings, current/parent/caller frame handles, return PCs and metadata loop indices. Every record is a fixed role in proof3--4: its significant fields have at most Cn bits for a universal constant C, stored in contiguous runs within a row, or in the explicitly untagged RAW bindings/frames/NEXT/head/virgin regions. In particular a descriptor's slot number occupies n bits in one descriptor row; a banked caller field/handle occupies a fixed O(n)-bit row field. All record roles and field ordinals are in the finite syntax, not an input-dependent symbol table. Logical P arrays and locals retain their existing owner/row layout. No new memory region is allocated.

For EVERY metadata field read or write the actual compiler emits the following WORD instructions, rather than looping over logical READ/WRITE separately per payload bit. A field ending at a row boundary is split there; a field of at most Cn bits intersects at most C+2 rows since WROW=2^16n. Each segment uses its own row tag. Known field bounds and caller bindings determine the addresses with the padded strides of proof4; bad arbitrary pointers are not legal compiler inputs. At ordinary aligned points all compiler-generated descriptors satisfy these bounds by proof3--7. The new compiler never adds a guard, source call or failure branch.

## 2. Literal tagged WORD instructions

READWORD(o,i,j,L), 0<=j< WROW, 0<=L<=WROW-j:
1. Form the known row base b and its tag/owner-epoch bases with the shift/copy/add generator.
2. Compare ALL EW tag bits to ep(o), using two running RAW pointers, one equality bit and staged bit/counters. Epochs are never held as ordinary words.
3. If unequal, emit L zero payload bits into a constant-size staged word; do NOT read stale value bits. If equal, stream RAW_READ(b+j+t) for t=0..L-1 into that word, advancing a pointer by literal ripple increments. L=0 makes no payload operation.
4. Return the staged field. This is at most O(n) bits; no row or array is buffered.

WRITEWORD(o,i,j,L,v), with staged payload v of L=O(n) bits:
1. Form the same bases, compare ALL EW tag bits to ep(o) bit-serially.
2. If tags mismatch, RAW_WRITE zero to EVERY one of the WROW values in this row, with one streaming pointer. Only after this full clear copy ep(o) into ALL EW tag bits, bit-serially. Do this even if v is all zero. No matching tag is published over uncleared values.
3. Stream RAW_WRITE(b+j+t,v_t) over the L positions. RAW_WRITE measures the old basis bit, applies a conditional X when needed, and forgets that old bit. If the original tag matched, preserve all other row values and all tag bits.
4. Forget the staged payload when the logical metadata transfer requires forgetting. For L=0 choose the identity instruction; no tag or value changes.

Multiple row segments are processed in increasing field order, with the payload staged at most once. A RAW-word field omits steps concerning tags and directly streams its significant bits; RAW padding is never interpreted. Leading zeros are read/written explicitly. Owner allocation writes the entire eight-word binding and its caller metadata field, including the current HEAD field, with these instructions; frame PUSH fully writes the sixteen RAW fields, including the current HEAD field. POP reads only initialized significant fields. NEXT/head/virgin retain the whole-word-before-read lifecycle of proof4. The controller uses a constant number of staging words and pointers throughout.

These are measured-basis operations, not a coherent WORD oracle. All bank/tag/RAW wires remain computational-basis classical records, possibly correlated with the mapped P quantum systems and arbitrary references. Gates on P quantum data remain exactly the mapped P gates, controlled by the same decoded bits.

## 3. Exact decoded-row and channel statement

Fix an active owner and let z be any allowed basis contents, including arbitrary stale values in mismatching rows. Decoding returns zero in EVERY position of a mismatching row, and stored values in a matching row. For a matching tag, READWORD returns exactly the decoded field and changes nothing. For a mismatching tag it returns the all-zero decoded field without exposing stale values. Thus it equals the result of the L logical READs in field order.

For a matching tag, WRITEWORD changes exactly the chosen field. For a mismatch and L>0, the literal series of L logical WRITEs first clears the entire row and publishes its tag at the first bit, then changes the field bits; the new instruction clears and publishes the same way and streams all bits. The final physical row is identical in both cases, including all unused/stale values and tags. For L=0 both are the identity by definition. This proves exact equivalence to the bitwise field transfer, including partial fields, all-zero writes and untouched neighboring fields. For a field crossing rows apply this argument to each segment. Epochs cannot change midway through a macro: the controller is sequential and exact renumbering occurs only during ALLOC_OWNER, never during an individual field transfer.

Extra reads of an already matching tag or a metadata value reveal deterministic functions of the existing basis record. Measurement leaves that basis record unchanged. For an arbitrary joint CQ state sum_z p_z |z><z| tensor rho_z on bank and P data/reference, apply the preceding equalities for each z, keep the SAME returned payload and decoded control, and discard the extra physical scratch outcomes. Linearity gives exactly the same decoded channel with the arbitrary reference retained. No independence of rho_z and z is asserted. WORD accesses never measure P's coherent slots.

Consequently proof7's decoded continuation and slot invariant holds at COMPLETE P steps/structural-transition boundaries. Inside a metadata macro, partial rows and scratch outcomes are not aligned points. Only the logical/coarse history of P is used in P's conditional yield, sigma-field, held-out-bit and decoding lemmas: no proof conditions on the compiler's extra tag/field reads. Forgotten physical scratch is traced out in the equality of decoded channels. ALLOC/FREE and exact renumbering retain proof5--6's generation invariant. Thus the logical law, success probability, acquisitions and deterministic caps are unchanged on successful, failed and aborted branches.

## 4. Complete bit-operation price

Let d=O(sqrt n) bound the GLOBAL address fee using the full physical prefix of proof8. Staged addresses/payloads occupy constant-many O(n)-bit words. Forming a row/tag/epoch/RAW-field start uses only power-of-two stride shifts/copies and a constant number of O(n)-bit ripple additions. Fixed field ordinals use constant-many such passes. All use O(n) bit operations and cost O(nd). No arbitrary multiply or table lookup is hidden in address formation. Metadata copies/comparisons/increments also use O(n) bit operations and pay d per operation.

For a segment of L successive RAW addresses the ripple-pointer bound is 2L+O(n) visited carry bits, for ANY initial bit pattern, including all-ones prefixes and long carries. Initialize the full staged pointer in O(n) operations. Each visited payload/tag/clear bit and each carry/test costs constant-many elementary operations. The total CHARGED work is O((n+L)d), not a favorable-average counter assumption. Streaming source/destination staged payload bit indices has the same bound (or a shorter O(log n)-bit counter), and its work is included. Every elementary operation, measurement, conditional X, loop test, carry and forgotten staged bit is paid at the global fee. A final increment can be omitted before overflow.

READWORD makes O(1) tag/epoch/field streams of total length O(EW+n)=O(n). WRITEWORD makes these plus, on EVERY miss, WROW=2^16n actual clear operations and EW tag writes. These are still O(n) with an absolute constant, on EVERY invocation, with no assumption of tag hits. Each instruction therefore costs O(nd)=O(n^(3/2)). Splitting a field into at most constant-many row segments preserves the bound, including separate complete clears in each. A matching single logical value-bit operation also has the old O(n^(3/2)) bound; an unmatched single WRITE may fully clear its row and has the same bound. No saving of logical P arithmetic steps is claimed.

ALLOC_OWNER first scans OWN=2^16r consecutive active flags, initializes/advances public pointers, performs the epoch increment/copy and streams binding/caller fields. The scan costs O((n+r)d); binding and epoch work cost O(nd). The total is O(n^(3/2)), EXCLUDING only the explicitly separately charged exact-renumbering phase when G is full. FREE_OWNER metadata/header work costs no more; CURRENT bound-list release iterations are separately charged per bound slot in lazy-native2--4, never priced as one constant-time owner header. All renumbering visits, clears, generator work and paused-frame preservation retain proof6's full bound; using the older conservative per-visit charge is allowed, and the total remains poly(n)2^((e+sig-1)sqrt n).

One slot allocation/free/descriptor-row update uses constant-many typed WORD fields and RAW word streams, constant-many O(n)-bit pointer comparisons/copies/additions, plus the same mapped P reset. Hence each wire event costs O(n^(3/2)); it makes no scan over HQ. One acquisition transfers n input qubits and initializes their O(n) descriptors/slot records, with O(n) wire events and constant-many owner/handle operations: O(n^(5/2)) including generation, swaps and acquired-register disposal. RAW slots and the ENTIRE padded prefix are initialized and disposed with their separate charged O(d DRAW) streams.
