## 4. Uniform controller, whole allocation and address fees

Preprocessing retains Q labels/score records, O(n²) classical bits; all originals are acquired despite an abort. Source probing t,h=O(n), O(n)-bit modular arithmetic and full gate addresses/generation give polynomial total work (O(n^9) is conservative). Classical Fisher–Yates uses in-place phase/label swaps. Coherent selection retains all m*d_sel raw range trials and their flags, copies the label array to quantum work, and realizes each selected swap by scanning ALL q positions. This is polynomial; no unknown/query bit selects a classical read address. Bad inputs take the same fixed finite loops.

List/capacity fields and loop/offset words have O(n) bits; native3 arrays are S=O(L). Save all comparator/Boolean/scan history, constant many independent marked-oracle/output/inverse regions, polynomial source/basis/probe/coin/arithmetic fields and inactive padding. Zero-phase apparatus is linear in the NUMBER OF MUTABLE V QUBITS, not its time. All together O(Ln^4) qubits. Oracle compute-phase-uncompute restores solver history for every search state, allowing actual reuse between Grover calls. Initialize/clear at charged cost. There is NO global quantumcount workspace. All nodebucket counts and canonicalinverse scans remain explicit bounded Boolean words.

The controller stores classical Q O(n)-bit records, public N/parameters/generated constants and fixed-nesting generator state. Bitonic loops have(K0,J0,i), scans(layer,lane,field), arithmetic has fixed-width bit/row loops. Elementary Boolean gates/Clifford+T decompositions are emitted directly. Inverse words reverse the same bounded loops/gates, never store an exponential classical circuit or read quantum comparison history. Constant nesting uses O(n) words of bounded width at worst O(n²) bits; even an O(n)-deep recursive equivalent with O(n)-bit frames fits. No exponential classical list is present.

Address generation is counted, not a free word operation. Maintain running region/row/record/field offsets. Elementary field addresses need a constant number of O(n)-bit additions/copies; these cost O(n) raw bit accesses and O(n²) WITH the full global indexed fee O(n). For bitonic partner i xor2^d, its record offset differs by plus/minus the PUBLIC shifted stride2^d*recordwidth. Scan partners similarly use shifted strides. Thus no fresh n-by-n multiplication is required for every emitted gate. Public region/stride setup and word-operation boundary arithmetic may cost O(n³), but occurs per bounded record operation/loop setup and fits under its conservative O(n²) emitted elementary gates times O(n²) generation budget (or the O(Sn^6) whole bound). Padding/comparator operations can retain this conservative allocation/gate budget; no actual free parallelism is assumed. Constant elementary templates have direct sequential offset iteration. Copying a whole O(n)-bit classical row at full fee costs O(n²), amortized over its emitted word. This establishes TOTAL solver work O(Sn^6)=O(Ln^6), including classical indexing and every quantum gate fee, not n² RAM arithmetic silently declared fee-free.

M counts ALL allocated classical bits/qubits, with log2(M+2)=O(n). Every genuinely indexed classical operation and every classically addressed quantum gate pays that FULL fee, including repeated inactive controls, measurements, initialization and resets. Quantum-selected accesses use the explicit scans/sorts. Polynomial-only pi/root/score routines can use the same bounded generators; their arithmetic workspaces are counted quantum histories, not hidden extra classical storage. Fixed data coefficients and finite code are generated, with no instance advice. These physical/controller choices are part of the ONE program; proof9 sums every source, failed attempt, word, address and allocated region.
