## 3. The exact virtual machine and its compact slots

Use P's finite uniform bit-controller code from virtual compiler Parts A and B,
with the full algorithms in its main, oracle, cap and dense appendices.
The stored G1 instructions are data generated by that finite controller.
They are not part of an unbounded free control program. All multi-bit
arithmetic is expanded into its counted bit operations. The virtual
primitive interface consists of fixed-size Boolean actions; local tape
reads, writes and head moves; indexed bit reads/writes; fixed-arity exact
quantum gates with ready operand fields; quantum measurement/reset/release;
source requests; and classical fair bits. A variable-length operation is
a loop of these primitives, not one primitive.

Fix the following finite-region slot implementation of P's documented
padded arrays and tapes. This is an address-layout choice for its ordinary
classical memory. It changes no abstract quantum action, numerical value, operation
order or source request. It retains the direct row/track arithmetic used
in virtual compiler A2 and the polynomial constructor in virtual oracle8.

table, fix a positive power-of-two integer C_t that bounds its capacity
by C_t(n+2)^2 in the source's complete simultaneous allocation proof.
These are fixed implementation constants determined by the finitely many
source templates, not values chosen from an input/history. Their existence
is established by the source bounds justified below; no runtime search
for an asymptotic constant is used. Give region t exactly W_t=C_t U
virtual bit slots. Let base_0=0 and base_t=sum_(h<t)W_h. A region-local
bit offset d is globally addressed by base_t+d, with 0<=d<W_t. The
region list and order are fixed:

## 4. Stable physical map and counted allocation

Virtual classical bit i is stored as the basis value of physical wire2i.
Virtual quantum wire q is physical wire2(q+1)+1. The reserved wire1 is
one reusable fair-bit scratch qubit. Thus the two kinds of data never
share a wire. This map is static arithmetic. No per-cell key, occupancy
flag, translation record, or address table is added by the simulation.
P's own allocation metadata is still present as virtual bank data.

Maintain one physical prefix of paired slots: all wires0,...,2h-1 are
allocated. Initially h=2. Before using a new virtual classical slot i,
ensure h>i; before using a new virtual quantum slot q, ensure h>q+1.
Double h until this holds, appending the new zero wires. Old wires keep
their indices and states. No bank copying or relocation is required.
The entire prefix, including its unused odd/even padding, counts in S_Q.
Reserving a region does not read its whole padding on every use. Each new
physical prefix wire is initialized once; P writes and clears its actual
logical fields and program markers in its original sequence. The final
whole-prefix cleanup is charged once at termination.
The maximum h is below twice max(2,B_P(n),H_P(n)+1). Hence its complete
size is O(n^2), even when the old logical allocation later shrinks.

This is an executable allocation rule; it needs no unknown runtime
constant in an O(n^2) preallocation. Its high-water bound uses the proved
fixed packed Dense layout in Section3. It must not be applied without
that argument to a machine that continually invents new sparse addresses.
Every growth allocates and initializes each new wire. The total number
of appended wires over the whole run is the final prefix size. Growth
loop control and address generation are counted in Section8.

Let a0=c0+4ceil(log2(n+2)) be the common virtual address/operand width
of virtual compiler B3 for the fixed layout in Section3. Choose the fixed
integer c0 large enough that 2^a0>B_P(n)+H_P(n)+2 and a0 accommodates
every stored address field, including program/constructor metadata, for
every n. Their capacity dependence on c0 is polynomial, so a fixed 2^c0
dominates it; all leading-zero field bits remain counted in their stated
regions.

Use a fixed staging width a=a0+4. It covers the doubled prefix, both
maps and the temporary source register. The actual total allocated
memory M is O(n^2); its full address fee ceil(log2(M+2)) is O(a).
For an upper bound, charge O(a) to every simulator bit/head action and
every indexed quantum action, even where a local classical action needs
no separate indexed fee. No address word is a unit-cost integer.

Retain N in its physical classical input tape, of n+1 bits or fewer.
Copy its bits to the virtual input slots if P uses such a copy. All
other virtual initial data and marker tracks are written by explicit
bank writes. The final n-bit residue can be streamed into an O(n)-bit
classical output field. Input and output may coexist and are both counted.

## 5. Basis read/write and complete address decoding

For a known physical classical address j=2i, define READ(i): measure
wire j in Z into one reusable classical result bit. Define WRITE(i,b):
READ(i), obtaining z; apply X to wire j exactly when z differs from b;
then clear/overwrite the temporary z when it is no longer needed. Both
operations are ordinary allowed circuits and classical control. A reset
to zero is WRITE(i,0). A read or write costs O(a) fully charged work
when its address is already ready. No old value or measurement history
is kept in an uncounted classical bank.

A fixed-size Boolean primitive first reads its fixed number of inputs,
performs the fixed Boolean operation in the physical controller and
writes its prescribed output bits. Read-before-write follows P's exact
order, including aliases. Long arithmetic uses P's bit loop; it is not
loaded as one long classical number. Its intermediate words remain
virtual bank data unless they are one of the short staging fields.

A virtual indexed access may specify its index by an a0-bit ready field
in the bank. Copy that field bit by bit into one physical a-bit field,
check its bound as prescribed by P, and form 2i by a counted shift.
The location of the ready field is supplied by the finite instruction
or a current virtual tape head. Any preceding calculation that locates
that field is itself part of P's counted bit execution. There is no
unbounded chain of free address indirections.

Here is a complete conservative cost for one short-field copy. Initialize
its start/end pointers and a physical marked strip of a0 positions with
O(a) raw bit/head actions. Visit the field's a0 bits in order. Each bank
bit measurement costs O(a). Pointer increments use the ordinary ripple
carry and return; over a0 consecutive increments from any start the
number of visited carry bits is O(a0+a)=O(a). This follows by summing
at most floor(a0/2^r)+1 changes at bit r. The output strip's head moves,
endpoint tests and rewinds cost O(a). Thus all classical pointer/strip
work is O(a) raw actions over this full scan and O(a^2) after the
conservative debit. Its a0 measurements also cost O(a^2). A short shift,
addition, comparison or range test uses O(a) bit actions and at most
O(a^2) charged work. A fixed number of such fields uses O(a^2) work
and O(a) physical classical bits.

The same estimate covers writing or updating a ready address field.
For one isolated virtual tape-head move, a full O(a)-bit carry walk and
return is allowed. Even without amortization its charged cost is O(a^2).
There is no claim of constant worst-case pointer work. Marked strips
and a fixed number of physical tape heads require O(a) bits in total,
including their head locations. They are not duplicated for every level.

A virtual fixed-arity quantum gate is dispatched only after every actual
operand field is copied from its virtual location. Compute each mapped
wire2(q+1)+1 by short-word arithmetic and use its ready physical address.
Each operand incurs its full address fee. The finite opcode and inverse
tag map are fixed; an exact Toffoli, if present, is expanded into its
fixed Clifford+T word. A stored G1 instruction is read in P's exact order,
including every tag, leading-zero operand bit, delimiter and marker.
The bank does not fetch an instruction or operand word coherently or in
one operation. P's program-head rewind and reverse interpreter execute
as actual simulated head/bit actions. Complete inverse gate words remain
in reverse order with their actual decoded operands.

The finite simulator also defines all these measurement/write channels
on arbitrary bank inputs. A decoded address outside the allocated virtual
interface may take a fixed abort-and-cleanup branch. That branch is not
reachable from P's specified initial state and valid control flow. No
unitary behavior, coherent RAM semantics or correctness theorem on an
unreachable superposition of classical records is assumed.

## 6. Quantum actions, source deliveries and discarded records

A gate on P's live quantum wires is applied identically to their mapped
physical wires. Its control qubit may be coherent. It never has a bank
address in coherent superposition. A quantum measurement of P produces
its original outcome in one small classical field; stream the outcome
into the prescribed virtual bit before using that field again. Register
measurements are emitted bit by bit as in P. A fresh classical fair bit
uses H and Z measurement of reserved wire1, writes that value as P
requires, and resets wire1 by conditional X. These are P's fair bits,
not additional source randomness or a selector change.

For a source request, first ensure the mapped source slot exists and is
zero as in P. Acquire exactly one specified DCP state in n+1 temporary
fresh source wires. If necessary, move it to that slot by n+1 SWAPs,
each a fixed three-CNOT word. The temporary source wires are then zero
and released. The temporary wires can use the range immediately after
the current prefix; they are released before any prefix expansion.
They cost O(n) extra qubits and O(na) work per request, in addition to
the mandatory n+1 source work. This fits O(a^2) times that virtual source
cost. It requests no second copy and performs no source preparation or
inverse. For a clean independent source the moved state is the same
rho_s, including every external reference on the existing workspace.

P's reset, release and discard are implemented by their allowed channel.
For a discarded qubit, Z measurement followed by outcome-controlled X,
with the result forgotten, is exactly trace-out followed by a fresh zero
on that slot. This statement is a channel identity with arbitrary
references; a surviving register is not assumed unentangled. The slot
can be reused without retaining unknown garbage. Count each measurement,
conditional gate, outcome clear and reset. Bank-cell release/reuse clears
its value and any original virtual metadata through the same bit process.
The paired prefix remains allocated and counted until final cleanup.

## 7. CQ invariant and exact clean-run equivalence

At each aligned virtual-step boundary the accessible state has the form

    sum_(c,z) p(c,z) |z><z|_C tensor |c><c|_B
                           tensor sigma_(c,z)_(D,R). (S2)

C is the physical controller, B the basis bank, D P's mapped live quantum
workspace, and R any other reference system. Here c is precisely P's
current virtual classical record. The control z contains finite control,
head positions and cleared short staging fields. The conditional D,R
state and classical distribution equal P's state under the same virtual
history. Histories can be merged when P forgets a classical value.
The mixture remains block diagonal; it need not be a product of the
bank and D. A stored measured label can be correlated with a coherent
Grover register through sigma_(c,z).

For a bank read, let P_b project onto strings with c_i=b. Applying its
nonselective measurement gives

    sum_b (P_b tensor I) omega (P_b tensor I)=omega.

Keeping the outcome only appends the deterministic bit c_i to C on
each term of (S2). It does not change that term's conditional D,R state.
Thus repeated instruction, label, address or program reads do not disturb
coherent Grover data conditioned on the actual classical record. This
uses CQ structure, not independence or a claim that measuring arbitrary
quantum storage is harmless.

A bank write maps each basis c to its exactly updated basis string c'.
If distinct records merge after an irreversible write, their conditional
states mix exactly as ordinary classical overwrite/forgetting requires.
The constant Boolean control steps and head moves update z identically.
A live quantum gate has P's same conditional action on sigma. Original
measurements and fair bits have the same instruments and then update
c. Discard/reset has the channel identity in Section6. Fresh clean source
delivery tensors the same independent rho_s at its prescribed request.
These facts prove (S2) inductively. At intermediate simulation microsteps
the bank is still CQ, although a virtual operation can be partly written.
All temporary read outcomes are released after their last use; no growing
physical classical transcript or simulator recursion stack is retained.

Consequently the entire reduced output channel and original source-request
sequence equal P's. One may couple all original measurements and fair
bits to the same values. Additional bank-read outcomes are deterministic
from the encoded record. Quantum reset/discard refinements, if exposed
inside the implementation, are immediately forgotten and give precisely
the required reduced channel. Wrong numerical labels, failed searches,
rejected copies, partial children, failed guards and abort cleanup are
covered. No correctness event or successful-path condition is used for
the simulation, allocation or work bound.

The original physical measurements inside Grover, G1, cyclic selection,
source extraction and the decoder are not replaced by bank measurements.
Only already-classical records are stored in B. Their extra readouts
reveal no previously coherent logical bank value because every reachable
bank record is basis encoded.

## 8. Complete physical space and simulation work

The input and output fields use O(n) physical classical bits. A fixed
number of a-bit physical address/operand fields, head locations, strips,
capacity/allocation words and finite instruction state use O(a)=O(log n)
more. Any longer counter, arithmetic numerator, profile, label, source/work
guard, constructor list, stored description or call context is virtual
bank data and uses the explicit read/write interface. The finite source
and simulator code have constant description size. Hence S_C=O(n).
No copy of the O(n^2)-bit virtual record is held classically.

The full paired prefix has O(n^2) allocated qubits. It includes bank
values, all original virtual-memory contents and metadata, stored G1
instructions, scratch, unused parity padding and original quantum slots.
The n+1 temporary source wires and constant coin scratch fit the same
bound. No per-cell O(log n) key or history record is added. Thus S_Q=O(n^2)
on every branch, including initialization, construction, failure and
release. All peak allocations count; the bank's basis character does
not remove it from the total M used for addresses.

A virtual raw bit/head/Boolean primitive costs O(a^2) charged simulation
work by Sections5--6. A virtual indexed bit access or fixed-arity gate
also costs O(a^2), including full operand-field decoding. Original fixed
size symbols/tags add only a constant number of such actions. Original
source events have virtual charge at least n+1 and their full simulation
cost fits the same multiplicative allowance. Every arithmetic instruction
has already been expanded into its real bit operations. There is no
unit-cost variable-width primitive in this bound.

The sum of all prefix expansions allocates O(B_P+H_P) wires. Conservatively
allow O(a^2) work per new wire for zero initialization, loop/index setup,
address dispatch and local control. At the end, first stream P's final classical residue from the bank into
the counted O(n)-bit physical output field. Then clear/release the whole
prefix and clear the short temporary fields, keeping the output field
until it is returned. These operations cost O((B_P+n+1)a^2) by the same
full-scan allowance. No inverse of P
or its source is used in cleanup. All quantum and classical work is
sequentially summed. For P's fully charged work T_P, therefore

    T_phys=O((T_P+B_P+n+1)*a^2).                    (S3)

P's acquisition and weighted guards remain exact virtual counters and
are checked at exactly the same virtual actions. Extra simulation work
is not falsely charged to those original nominal guards. Instead (S3)
counts that work separately for every executed primitive and every final
partial/abort path. It is an all-branch upper bound on the one simulator.

## 9. Strict internal time margin

Do not multiply P's final declared pure exponential and silently remove
the simulation factor. Dense virtual main9.5 and virtual dense11, using the full compiler,
prove the stronger internal work bound

    T_P=O(n^2 L log2(L+2) 2^R),                    (S4)

where R is the unchanged least feasible profile parameter. B_P=O(n^2)
and a=O(L) for n>=2. Equations(S3)--(S4) imply

    T_phys=O(n^2 L^3 log2(L+2) 2^R+n^2 L^2).

Since R>=1, log2(L+2)>=1 and L>=1, the added term is included in

    T_phys=O(n^2 L^3 log2(L+2) 2^R).               (S5)

The fixed bound appendix proves for L>=65536

    R<=ceil((283/400)sqrt(nL)),
    2^R<=2*2^((283/400)sqrt(nL)),
    3L<=(1/2000)sqrt(nL).                         (S6)

Its capacity proof does not assume monotonicity of the retained sum.
For L>=65536, log2(L+2)<=L, so log2(log2(L+2))<=log2 L.
Also 4log2 L<=L: it holds at L=16 and L-4log2 L increases thereafter.
Thus the logarithm of the new polynomial factor in (S5) is at most

    2L+3log2 L+log2(log2(L+2))
       <=2L+4log2 L<=3L.

Use (S6) and the exact gap177/250-283/400=1/2000. This gives

    T_phys=O(2^((177/250)sqrt(nL))).                (S7)

There is no new execution threshold or parameter. At all smaller bit
lengths the same original finite/normal branch and the same simulator
run. Their existing all-branch caps and (S3) give a finite maximum ratio
to the positive target envelope. That finite prefix changes only one
absolute outside constant. This includes n=1 with its explicit finite
branch. The internal .7075-to-.708 gap is used after proving the new
simulation work, not as a claim of a faster operational profile.

## 10. Copies, model and success

There is exactly one physical source request for each virtual request
and no other request. Fresh zero bank/padding qubits are not DCP copies;
their preparation has already been counted. All original source attempts,
failures, discarded/rejected states, partial children and aborts therefore
have the same actual source count. The exact acquisition guard is still
Qcap_dense. The two source corrections and the whole uniform Q envelope
in (S1) remain those proved in virtual main9.3/cap R8a/virtual dense11 and the bound
appendix. This transfer changes no probability, precision or guard proof.

The output-channel equivalence in Section7 transfers P's unconditional
full-secret success at least1-2^-8. It uses the complete fixed Dense proof,
not an acceptance or review verdict. The exact clean-model string remains:

Malformed fraction among acquired copies. The proved guarantee requires every copy to be an independent ideal coset state; no behavior is promised for malformed copies.

No positive tolerance is claimed. In particular an adaptive supplier allowed
to see all actual measurement outcomes could see additional bank values
under this implementation. Its later choices need not have the same law
as in the virtual machine. The independent clean-copy source has no such
feedback choice, so that issue does not enter the theorem. No adaptive
extension follows from this note or from the prior clean transfer.

Both T and Q representative envelopes in (S1) have index1/2: their
logarithms have leading term(177/250)sqrt(nL), and the negative source
terms are lower order. The two polynomial space envelopes n and n^2
have index0. These are upper-bound indices, not runtime lower bounds.
