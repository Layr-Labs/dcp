# Cyclic-window merges (normative P Sections6.2, A and B)

This file replaces power-of-two block truncation by an overlapping cyclic
window. It contains the complete binary merge, four-input merge and fresh-
digit failure analysis used with kappa=20. The retained LOOKUP is the serial
circuit in P Section6.1; no quantum-addressed bank access is used.
In this file R_s=ceil(sqrt n) denotes the global schedule scale. The r,r'
in SectionA and its counting formulas are the local residue-window widths.

## W. Exact cyclic-window instrument

Let a known rank register R have q bits and support [0,m), m>=L'=2^lam'.
It may be entangled with an old tuple register U, where U=u_R is a known
injective table. The rank part W_rank prepares fresh lam' qubits J in |0>, reset as in P Section2,
and apply H to each. In-place apply R<-R-J mod m on R<m, and the identity
on R>=m. Measure R=t and reset R without releasing it. The caller completes
W by constructing Inv[j]=u_((t+j)mod m) for j=0,...,L'-1; serial LOOKUP
controlled by J XORs Inv[j] into U, clearing U to zero. It then resets/releases
U and keeps J with its phase table. Calls to W_rank below perform only the
rank part; each caller performs this inverse-lookup completion exactly once.

For uniform-magnitude input m^-1/2 sum_r exp(i theta_r)|u_r>|r>, after completion the output
conditioned on t is L'^-1/2 sum_j exp(i theta_((t+j)mod m))|j> and t is uniform
on [0,m). Every window has L' distinct ranks, including a wrap across m.
This follows by substituting r=(t+j)mod m in the joint state after the
permutation. More generally its Kraus operator is

    K_t=(1/sqrt(L')) sum_(j<L') |j><(t+j)mod m|.

Each input rank belongs to exactly L' windows, and each window map is
injective, so sum_t K_t^dagger K_t=I. Thus there is no discarded partial
block when m>=L'. Fresh source copies are never reset by this construction.

Circuit for modular subtraction. For each bit v of J, apply, controlled
by that bit, the known permutation f_v(r)=(r-c_v)mod m for r<m, and r
otherwise, where c_v=2^v mod m. The valid interval is invariant, so the
composition is exactly R-J mod m there and identity on its complement.
An explicit reversible implementation computes this piecewise function
into a clean q-bit target T, swaps R,T, and XORs the inverse piecewise
function into T to clear it. The inverse uses addition c_v mod m. For valid r, subtraction is r-c_v+m*[r<c_v], while inverse addition is
r+c_v-m*[r+c_v>=m]; invalid r and a zero control retain r. Both
Boolean functions are built from ripple addition/subtraction, comparison
with known m and multiplexing with the valid-domain/control flags. They
use O(q) Boolean gates; computing each into fresh scratch, copying outputs
and reversing gives clean Toffoli/CNOT/NOT circuits with O(q) scratch.
One may conservatively charge O(q^2) gates per controlled shift. Constants
c_v are generated by modular doubling in known-address bit arithmetic.
No arithmetic branch is controlled by a superposed memory address: J bits
are ordinary quantum gate controls on fixed wires.

This defines a permutation on every padded q-bit R encoding for each J,
not only on promised inputs. Here q=O(sqrt n), lam'=O(sqrt n), so even the
conservative O(lam' q^2) extra gates and local uniform emission are polynomial
per merge, below the retained table-work allowance on the main branch.
At the fixed parameters q<=2R_s+1. Ripple add/compare/multiplex circuits
use fewer than128(q+2) temporary Boolean bits, reused between the two
functions and controlled shifts. With T and J this adds fewer than2^10 R_s
qubits. The original fixed lists have fewer than2^8 families of at most4n
qubits, apart from the separately counted index stack and growing FW
scratch. Together the fixed scratch remains below c0 n with c0<=2^12; the growing FW
scratch is still separately bounded by c_F. All initializations/releases
receive the explicit resets of P Section2.

## 6.2 Binary MERGE with cyclic windows

Precondition: X1 and X2 are phase vectors from disjoint sets of qubits, both of length 2^lam,
collimated to p, with index registers x, y and tables al, be. Let cA = al[0] mod 2^p,
cB = be[0] mod 2^p, car = floor((cA + cB)/2^p), aa[x] = floor(al[x]/2^p) mod 2^b and
bb[y] = floor(be[y]/2^p) mod 2^b. Then bits p..p+b-1 of al[x] + be[y] equal (aa[x] + bb[y] + car)
mod 2^b. (If b = 0 the residue registers below are empty and e = 0.)

1. LOOKUP aa into a fresh b-bit register Ru and bb into Rv. Add Ru + Rv + car (mod 2^b) cleanly into
   a fresh Rz, and clear Ru and Rv by repeating both lookups. Measure Rz, obtaining e, and reset Rz.
2. Classical. Let S_e = {(x,y) : aa[x] + bb[y] + car = e mod 2^b} and sz = |S_e|. Merge-sort the
   indices y by key (bb[y], y) into order[]; pos[y] is the position of y. For each x the partners y
   form one contiguous run of order[], the class (e - car - aa[x]) mod 2^b; find its start lo[x] and
   length cnt[x] by binary search. Put off[x] = sum_(x' < x) cnt[x'] and
   rank(x,y) = off[x] + pos[y] - lo[x], a bijection from S_e onto [0, sz). If sz < 2^lam', declare FAIL.
3. Let R have 2 lam + 1 bits. LOOKUP pos into Rp and Dx[x] = (off[x] - lo[x]) mod 2^(2lam+1) into Rd.
   Add Rp + Rd (mod 2^(2lam+1)) cleanly into a fresh R, and clear Rp and Rd by repeating the lookups.
   On S_e, R = rank(x,y).
4. Apply W_rank to rank R with m=sz and target L'=2^lam', keeping a fresh J.
   The measured window origin t is a known integer in [0,sz).
5. For j in [0,L'), put rj=(t+j)mod sz. Find the least x with
   off[x]+cnt[x]>rj by binary search on the nondecreasing end offsets;
   then y=order[lo[x]+rj-off[x]]. Store Inv[j]=(x,y) and
   lab[j]=al[x]+be[y]. Serial LOOKUP on J clears x,y as in W.
6. Output J with this table; reset/release R and all other scratch/inputs
   as prescribed, keeping only J. On FAIL reset/release both inputs and
   all allocated registers, never reusing those inputs.

Correctness. The residue measurement leaves equal magnitudes on S_e and
rank is a bijection onto [0,sz). W therefore gives a uniform phase vector
on the selected L' distinct pairs with their original sum phases. Every
label is congruent to cA+cB+2^p((e-car)mod2^b) modulo2^(p+b), so collimation
is unchanged. Inverse lookup clears the old indices exactly. Choosing a
window is not a measurement of higher label digits: t is uniform given
the low-bit fiber size. Its law is phase-independent.

Lemma6.1 (distribution-free law). For any collimated input tables, all
measurement/failure laws depend only on label bits below p+b and

    Pr[FAIL]=sum_e sz_e 1[sz_e<L']/L^2 <= 2^(b+lam'-2lam).

Here L=2^lam. Outcome e has probability sz_e/L^2. If its fiber is large
enough W always succeeds; otherwise the routine fails. Bounding each
short fiber by L'-1 proves the inequality. b=0 is allowed. The stronger
conditional bound needed for constant kappa is proved below.

The old classical arrays aa,bb,order,pos,lo,cnt,off,Dx are retained. Inv has
L' rows and can replace the old block-inverse array. Binary search per
output costs O(lam^2), and labels cost O(n) per row, so the retained
O(n(L+L')) skeleton bound holds on fixed main-branch parameters, with an
additional polynomial O(lam' q^2) window module. As lam>=dl>=R_s/2 and 2^(R_s/2)>=n on the main branch, this
polynomial and its full uniform emission fit O(n(L+L')).
Quantum scratch remains O(sqrt n) beyond the input/output indices.

## A. Four-input MERGE4I with cyclic windows

Precondition: X1..X4 are phase vectors from pairwise disjoint sets of copies, of length L = 2^lam, collimated
to p, with index registers x1..x4; write lab_t[x] = c_t + 2^p h_t[x] (0 <= c_t < 2^p), as collimation allows; lam >= kappa + 2,
lam + 1 <= l <= 2 lam, r = 2 lam - l, lam' >= 1, r' = 2l - lam' - kappa >= 1 (kappa as in Section 0). Put
b = r + r', mX = 2^l = L^2/2^r, mu4 = 2^(lam' + kappa), Cp = 8 mu4 + 1; so 2r + r' = 4 lam - lam' - kappa. Residues:
rho_t = h_t mod 2^r (window W0: bits p..p+r-1) and sg_t = floor(h_t/2^r) mod 2^r' (window W1: bits p+r..p+b-1). Carries: cAB = floor((c_1 + c_2)/2^p),
cCD = floor((c_3 + c_4)/2^p), cq = floor(((c_1 + c_2) mod 2^p + (c_3 + c_4) mod 2^p)/2^p), and
car = floor((c_1 + c_2 + c_3 + c_4)/2^p) = cAB + cCD + cq. For a pair (x1, x2) let
vX = (rho_1 + rho_2 + cAB) mod 2^r (bits p..p+r-1 of lab_1 + lab_2), gX = floor((rho_1 + rho_2 + cAB)/2^r) in
{0,1}, and the key kX = sg_1 + sg_2 + gX in [0, 2^(r'+1)); define vY, gY, kY for (x3, x4) with cCD.

Window identity. With h_t = rho_t + 2^r sg_t + 2^b u_t and S = lab_1 + lab_2 + lab_3 + lab_4 for a tuple,

    floor(S/2^p) = car + h_1 + h_2 + h_3 + h_4 = (vX + vY + cq) + 2^r (kX + kY) + 2^b (u_1 + u_2 + u_3 + u_4),   (6.4)

as cAB + rho_1 + rho_2 = vX + 2^r gX and cCD + rho_3 + rho_4 = vY + 2^r gY. So bits p..p+r-1 of S are
(vX + vY + cq) mod 2^r, and bits p+r..p+b-1 are (kX + kY + c0) mod 2^r', c0 = floor((vX + vY + cq)/2^r) in {0,1}.

1. LOOKUP rho_1, rho_2 into fresh registers, add them and cAB mod 2^r cleanly into a fresh Rz, clear the two by
   repeating the lookups, measure Rz (outcome v), reset it. Same on x3, x4 with cCD (outcome v2). Let the pair fibers
   X_v and Y_v2 be the sets of pairs (x1, x2) with vX = v and (x3, x4) with vY = v2.
2. Cutoff (classical). Merge-sort the x2 by (rho_2, x2) and the x4 by (rho_4, x4). For each x1 the x2 with
   rho_2 = (v - cAB - rho_1[x1]) mod 2^r form one contiguous run, found by binary search; the run lengths sum to
   |X_v|, and likewise for |Y_v2|. If either size is below mX/2 or above 2 mX, declare FAIL.
3. LOOKUP h_t mod 2^b (t = 1..4), add them and car mod 2^b cleanly into a fresh Rw, clear the lookups, CNOT bits
   r..b-1 of Rw into a fresh r'-bit Ru, and uncompute Rw. Ru holds bits p+r..p+b-1 of S. Measure Ru (outcome v'),
   reset it. Let Z = {tuples of X_v x Y_v2 with bits p+r..p+b-1 of S equal to v'}, sz = |Z|.
4. Listing (classical). Re-sort the x2 by (rho_2, sg_2, x2) and the x4 by (rho_4, sg_4, x4): the runs are the
   same sets (their ends found again by binary search on rho_2), with sg nondecreasing along each, and gX is constant on the run of x1. STREAM X, a class-restricted Schroeppel-Shamir stream: a min-heap holds, for
   each x1 with a nonempty run, the key kX of x1 with its next unread run position; pop the minimum, output that
   pair, push the next position of that run. As kX is nondecreasing along runs, STREAM X outputs X_v once each in
   nondecreasing kX. STREAM Y outputs Y_v2 in nonincreasing kY likewise (runs read backwards, max-heap). Each heap
   holds at most L entries of O(lam + r') bits. Neither X_v nor Y_v2 is stored as a table: the stored data are the
   sort orders, runs, heaps, Buf (at most Cp pairs of one run) and Tl.
   Put c0 = floor((v + v2 + cq)/2^r) and tg = ((v' - c0) mod 2^r') + g 2^r' (g = 0..3). As
   0 <= kX + kY <= 2^(r'+2) - 2, by (6.4) a tuple of X_v x Y_v2 is in Z iff kX + kY = tg for exactly one g. For
   g = 0..3 in order, restart both streams and scan with heads hx, hy: if kX(hx) + kY(hy) < tg read the next X
   pair (rule 1); if > tg read the next Y pair (rule 2); if = tg (rule 3) read the whole run of Y pairs with key
   kY(hy), keeping the first min(run length, Cp) of them in a buffer Buf, then the whole run of X pairs with key
   kX(hx), appending to a list Tl the 4-tuple of each X pair read with each Buf entry. Stop the listing as soon
   as |Tl| = Cp; a scan ends when a stream is exhausted.
   Claim: if sz <= Cp, Tl lists Z exactly once each; otherwise Tl lists exactly Cp distinct elements of Z.
   Proof. Appended tuples have kX + kY = tg, so they lie in Z; they are distinct, as a scan reads each pair once and
   a tuple has only one g. Let (xi, eta) be in Z with
   kX(xi) + kY(eta) = tg, in a scan without stop. While eta is unread, kY(eta) <= kY(hy), so rule 1 cannot pass
   over xi; while xi is unread, kX(xi) >= kX(hx), so rule 2 cannot pass over eta. So the first step reading xi or
   eta is a rule 3 step with both unread before it; there kX(xi) >= kX(hx), kY(eta) <= kY(hy) and equal sums give
   kX(xi) = kX(hx) and kY(eta) = kY(hy), so both lie in the runs read whole, and (xi, eta) is appended unless Buf
   cut its Y run. Buf cuts a run only if it has more than Cp pairs; its X run is nonempty, so the first X pair
   read fills Tl to Cp, and then sz > Cp. QED. Let tl = |Tl| = min(sz, Cp).
   Before the measurement of v', no branch or FAIL decision of this merge depends on label bits at positions
   >= p + r: the only one, in step 2, depends on bits below p + r.
5. If tl<L'=2^lam', declare FAIL. Otherwise allocate R of
   ceil(log2(Cp+1)) bits and one qubit Rf, both zero. For each Tl row rho,
   compute tuple equality with (x1,x2,x3,x4), CNOT it into Rf and the bits
   of R encoding rho, then uncompute the equality. Distinct rows give
   R=rho,Rf=1 on Tl and R=0,Rf=0 elsewhere. Measure Rf; if0, FAIL.
6. On Rf=1 apply W_rank with m=tl to R and target L', keeping fresh J and
   measured origin t. Construct Inv[j]=Tl[(t+j)mod tl] and lab[j] as the
   sum of its four original input labels.
7. Serial LOOKUP on J clears x1,...,x4 using Inv; reset/release those
   indices, R, Rf and scratch. Output J with lab. It has the same
   collimation constant given by (6.4), since every selected tuple is in Z.
On every FAIL all inputs/registers are reset/released, never reused.

Correctness. The original steps1,3 and the Tl projector produce uniform
magnitudes over the listed tuples. W gives a phase vector on L' distinct
listed tuples, with unchanged sum phases. Its tuple map is injective even
if it wraps around the end of Tl. Thus the original source-coordinate
incidence and distance properties continue to hold. No incomplete-block
FAIL remains; only cutoff, Tl overflow and short fibers can fail.

LemmaA.1 (failure identity). Let cut mean either pair size lies outside
[mX/2,2mX]. Then

 Pr[FAIL]=sum_cut |X_v||Y_v2|/L^4
   +sum_noncut sum_v' [(sz-tl)+sz 1[sz<L']]/L^4.             (CW.1)

The first residue measurements have mass |X_v||Y_v2|/L^4. Conditional v'
has mass sz/(|X_v||Y_v2|). If tl<L', then sz=tl<L' since Cp>=L', and
all that mass fails. Otherwise Rf failure has mass (sz-tl)/sz and W has
no further failure. Multiplication gives (CW.1). The origin t is uniform
on the retained fiber; all these probabilities depend only on current
low label digits, not phases or future digits.

All original sort orders, runs, heap streams, Buf and Tl are retained.
Inv can replace the block table. The extra lower-size cutoff has no new
asymptotic work. The same standalone skeleton bound
O((L+mX)lam(lam+b)+Cp lam+L'(lam+n)), plus the polynomial window module,
and the same array caps hold. On the fixed schedule the polynomial module
fits the existing per-attempt table budget; all failed calls get that full
upper bound. Extra J has the same width as the former retained low-R
output, while temporary modular arithmetic fits the fixed scratch cap.

## B. Fresh-digit failure bounds

The ideal-run conditioning Hp includes all earlier controller decisions and
outcomes, except label bits at positions>=p for leaves of the present inputs.
It retains their bits below p and everything on other copies. As in the
retained held-out-bit proof, it excludes LE's internal coins/tests, which
feed no ideal decision, and excludes current-batch root measurements taken
after BATCH. Full high input-label fields exist as data, but are not part
of this logical conditioning. Entries have Hp-measurable distinct 0/1
source incidence sets; input vectors use disjoint source sets.

Conditional fresh digits. Every earlier step involving these leaves used
label digits below its own final collimation boundary<=p. FW/group selection
uses low keys and phase-independent outcomes; lower merges use only their
own low-bit fibers. Cyclic-window origins are uniform given low fiber sizes
and are phase-independent. Thus those likelihoods and choices depend only
on source digits below p. Source acceptance leaves independent uniform
labels on the required power-of-two range; p+b<=B<d_src. Dropping unused LE
internal records preserves that law. Therefore all source digit blocks in
the present window are independent uniform, conditional on Hp. For the
four-input routine split them into g_j in [0,2^r) and g'_j in [0,2^r');
conditional on Hp'=Hp plus g_j, the g'_j remain independent uniform.
Carries from lower digits are measurable in the relevant conditioning.
This is the same factorization used in the retained MERGE4I proof, now
including the explicitly phase-blind cyclic-window outcome law.

Pairwise-count lemma. Suppose a measurable family has distinct measurable
incidence sets I(e), and residues f(e)+sum_(j in I(e))z_j mod2^s, with the
z_j independent uniform given H and f(e) H-measurable. For s>=1 each
nonempty I(e) gives a uniform residue. For two distinct nonempty sets take
j in their symmetric difference, say j is in I(e') but not I(e), and i in
I(e). With other coordinates fixed, the two residues are an invertible
linear map of (z_i,z_j): its matrix is [[1,0],[1,1]] if i is also in I(e'),
and the identity otherwise. Both are invertible over Z/2^s. Thus fixed-
residue indicators are pairwise independent and their count S has
Var(S|H)<=E(S|H). At most one entry in a distinct family has empty incidence;
remove it for this lemma, adding at most1 to a fiber count. For s=0 all
residues are deterministic and the corresponding bounds follow directly.

### LemmaB.2: binary short fibers

Let mu=L^2/2^b, L'=2^lam', kappa=20, and b<=2lam-lam'-kappa. Then,
conditional on Hp,

    Pr[FAIL] <= 4 L'/mu^2 <= 4*2^(-lam'-2kappa).           (CW.2)

For b=0 the single fiber has size L^2>=L' and never fails. Otherwise, for
fixed e the nonempty-pair count has mean nu in [mu-1,mu] and variance<=mu.
Every pair has a distinct incidence set because the inputs use disjoint
source sets. Since mu>=2^(lam'+20), nu-L'>=mu/2. If sz_e<L', its nonempty
count is also below L'. Chebyshev gives probability<=4/mu. By Lemma6.1
and linearity of expectation, its measurement mass is bounded by

    sum_e L' Pr(sz_e<L'|Hp)/L^2 <= 2^b L'(4/mu)/L^2.

This is (CW.2). The bound averages only unexposed fresh digits; it is not
an assertion that each deterministic table has well-populated fibers.

### LemmaB.1: four-input cutoff, overflow and short fibers

With the stated MERGE4I parameters, conditional on Hp,

 Pr[FAIL] <=22*2^(-l)+2^(-kappa-lam')+2^8*2^(-lam'-2kappa). (CW.3)

First pair window. For fixed v the nonempty-pair count S has mean
nu in [mX-1,mX], variance<=mX, and |X_v|<=S+1. If |X_v|>2mX, let
D=S-nu>=mX. Then |X_v|<=D+mX+1<=3D<=3D^2/mX, so
E[|X_v|1(|X_v|>2mX)|Hp]<=3. The same holds for Y.
For the new lower cut, mX>=4 and nu>=3mX/4. If |X_v|<mX/2 then
S<mX/2, a downward deviation of at least mX/4. Its probability is at
most16/mX, and its weighted size expectation is at most8. Summing either
upper/lower cut mass over residues, using sum_v |X_v|=sum_v2 |Y_v2|=L^2,
gives at most(3+8+3+8)2^r/L^2=22*2^(-l). If r=0 the pair fibers are
both all L^2 pairs and neither cutoff occurs, so this bound holds directly.

Second window. Condition on Hp'. On an uncut pair of fibers,
N=|X_v||Y_v2| lies in [mX^2/4,4mX^2]. For fixed v', let S' count
nonempty tuples in its second residue. The incidence family remains
measurable and distinct, so its mean nu satisfies

    mu4/4-1 <=nu<=4mu4,   Var(S'|Hp')<=4mu4,
    mu4=mX^2/2^r'=2^(lam'+kappa).

Also sz<=S'+1. As Cp=8mu4+1, the overflow obeys
(sz-tl)<= (S'-8mu4)_+. On S'>8mu4, D=S'-nu>4mu4 and
S'-8mu4<=D<=D^2/(4mu4). Thus E[sz-tl|Hp']<=1. Summing over
at most2^(2r+r') triples and dividing by L^4 gives the overflow term
2^(2r+r')/L^4=1/mu4=2^(-kappa-lam').

For short fibers, kappa=20 implies nu-L'>=mu4/8. Therefore
Pr(sz<L'|Hp')<=Var(S'|Hp')/(mu4/8)^2<=256/mu4. The identity
2^(2r+r')/L^4=1/mu4 now bounds the total expected short-fiber mass by

    (number of triples)/L^4 * L'*(256/mu4)
       =256 L'/mu4^2=2^8*2^(-lam'-2kappa).

The uncut condition is Hp'-measurable; taking expectations over Hp' and
then Hp proves (CW.3) from (CW.1). No outcome of the present attempt is
included in Hp. On retries the discarded inputs are never reused, so the
same conditional bound applies to each fresh attempted merge.

### CorollaryB.3: internal and root bounds at the fixed schedule

The size facts give Lam>=R_s/2 and dl>=7R_s/12. Every nonroot binary output
has lam'>=dl and every nonroot four-input output has lam'=Lam, while
l>=Lam+1. Hence both kinds of internal merge fail with conditional
probability at most24*2^(-R_s/2)<1/(4R_s). The inequality follows from
2^(R_s/2)>96R_s at R_s=2^20 and then monotonicity. At the unique root lam'=1:
binary failure is at most2^-39; four-input failure is at most
22*2^(-R_s/2)+2^-21+2^-33<1/16. These bounds replace the old requirement
2^kappa>=16R_s. They hold with constant kappa=20, on every ideal logical
history described above, and for every shift.

The source/phase-vector invariants used here are preserved by cyclic
windows: every chosen output entry is an original input tuple's label sum,
the chosen tuple map is injective, and different inputs use disjoint source
coordinates. New window outcomes read no future label digits and have
phase-independent laws. Therefore the same induction justifies both these
fresh-digit lemmas and the subsequent held-out-bit block decoder.
