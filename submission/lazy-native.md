## 2. Actual virtual-zero and ownership instructions

P scratch allocation creates a logical register/container whose descriptor cells initially decode to zero under its fresh lazy owner epoch. A zero descriptor means a virtual |0> qubit that has not been touched. It does NOT mean a copy of an unknown P state. No physical slot is obtained and no individual descriptor row is initialized for this declaration. The existing counted descriptor array/owner and RAW binding are sufficient; initialize binding word8 HEAD=0. For a mixed pool/table array, this HEAD concerns only its semantically owned quantum handles, not its numerical P data. Classical arrays with no owned qubits keep HEAD0.

Maintain the typed distinction between a REGISTER REFERENCE and a published individual QUBIT HANDLE. A whole-register alias holds the same canonical descriptor-owner/row/field map; it does not copy zero descriptor payloads to create independent identities. BEFORE the compiler copies/publishes an individual handle outside its canonical descriptor map, it binds that logical qubit and copies k+1. This rule includes an individual record/row transfer even if the qubit is still a pure zero. Zero is NEVER copied as an opaque qubit identity. Binding before publication is essential: otherwise two aliases could later allocate different slots for one qubit. Bound handle k+1 retains identity until P releases that qubit; all live aliases refer to that same slot. P's handles are opaque: its numerical comparisons/sort keys use explicit P labels/row indices, never the physical slot number. The source P5 lifetimes prohibit use after release. A whole-register handle that remains live retains its canonical descriptor owner; a partial transfer publishes the selected individual handles before any old array owner is freed.

ENSURE(q): resolve q's current typed reference/handle. If its canonical descriptor is0, call low-level ALLOC_Q, write k+1 into the canonical descriptor, and insert slot k into that lifetime-container's bound list. If already bound, return its slot. Before every P gate/measurement/reset ENSURE every quantum operand, at most three. Before per-qubit handle publication likewise ENSURE; a later copied bound handle does not bind again. Source acquisition ENSUREs all n+1 target positions BEFORE swapping the unknown rho_s register into them; source copies are never assumed zero. All descriptor/tag/owner/address/slot/list operations are charged WORD instructions. Register references and P by-value numerical copies retain their distinct semantics.

Each binding record's former eighth reserve word is HEAD, storing slot+1 or0. Add RAW PREV[k] and OWNER[k] words, stride NS, in addition to NEXT[k]. OWNER stores the current active lifetime-container owner ID. For bound slots, NEXT/PREV use encoded pointer k+1,0 empty. For free slots NEXT instead stores the low-level raw free-stack pointer or HQ sentinel. The partition invariant determines the role before reading; no bit string is interpreted ambiguously. All changed significant words, including leading zeros, are written in full before later interpretation. Untouched PREV/OWNER/NEXT words are never read.

INSERT(k,o): read h=HEAD[o]; set PREV[k]=0,NEXT[k]=h,OWNER[k]=o; if h!=0 set PREV[h-1]=k+1; set HEAD[o]=k+1.
UNLINK(k): read o=OWNER[k],p=PREV[k],z=NEXT[k]; if p!=0 write NEXT[p-1]=z, otherwise HEAD[o]=z; if z!=0 write PREV[z-1]=p. Intermediate partial links are not aligned points.
BIND: low-level ALLOC_Q obtains a free/virgin independent-zero slot, then INSERT and write the descriptor.
RELEASE_BOUND(k): UNLINK; reset the P quantum state at k exactly when P releases it; low-level FREE_Q writes NEXT[k]=head in free-stack format and head=k. The remaining stale PREV/OWNER words are not interpreted while free. A later INSERT overwrites them before the bound role.
MOVE_OWNERSHIP(k,o_new): UNLINK, then INSERT at o_new. It does not change or clone the state, and it does not change the bound handle value k+1. A register/array's ordinary copied aliases do NOT invoke this instruction. Only P's semantic lifetime transfer invokes it.
DESTROY_CONTAINER(o): while HEAD[o]!=0, release that bound slot by the previous instructions; then invalidate/free the owner as P specifies. This loop follows ONLY bound live slots. Unbound virtual qubits and unused descriptor rows are discarded by the owner/lifetime abstraction, without scanning or clearing them. No scan of virgin/HQ/all owner rows occurs. If the same owner ID is reused, its fresh epoch, complete RAW binding/head overwrite and source allocation rule prevent stale descriptors from being read.

The header/links track UNIQUE lifetime ownership, not every classical handle location. All pool scratch copies, sorting copies, buffer aliases and caller arguments retain ordinary opaque aliases. The source ownership annotations are: a newly allocated register owns its scratch; each acquired original's registers own its n+1 bound slots; FW inputs belong to their current chunk/LIVE containers, released inputs are removed, kept/recycled outputs transfer to OUTPUT/buffer ownership; PREP R_N and other ancillas belong to their temporary scratch register. Each LEAF output and each MERGE/MERGE4I/MERGE7 surviving index register owns its kept qubits; removed input/scratch qubits are released. Passing a whole surviving register passes its owner binding; moving selected qubits to a new descriptor array updates their lifetime list. P5 lists every kind of release/keep/transfer, including rejected PREP tries, failed merges and aborts. After a transfer old classical aliases may remain in arrays P will no longer use for that quantum lifetime; destroying those arrays does not release transferred-out slots. Their old heads no longer contain them. No source numerical label is changed by these ownership annotations.

A partial register release can individually clear its canonical descriptor before its later legal use; whole-container destruction instead invalidates the owner. No dead handle is read after its logical release. On global ABORT or terminal output-first cleanup it is also legal to discard the entire counted prefix directly, matching P's global discard; that distinct O(d DRAW) cleanup is charged, not a slot/owner scan hidden in the fast event price.
